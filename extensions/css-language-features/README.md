# Language Features for CSS, SCSS, and LESS files

**Notice:** This extension is bundled with Visual Studio Code. It can be disabled but not uninstalled.

## Features

See [CSS, SCSS and Less in VS Code](https://code.visualstudio.com/docs/languages/css) to learn about the features of this extension.

### Drop or paste resource links

Drop workspace files into a CSS, SCSS, or LESS document to insert quoted `url()` functions with relative paths. Pasting copied file resources offers the same edit through **Paste As**. Filenames containing spaces or URL delimiters are encoded, and external URL queries and fragments are preserved.

Use the drop or paste edit picker to choose **Insert url() Function** (or **Insert url() Functions** for multiple resources). Within an existing `url()` expression, quoted string, or comment, the ordinary path edit is preferred so that a second `url()` function is not inserted by default.

Please read the [CONTRIBUTING.md](https://github.com/microsoft/vscode/blob/master/extensions/css-language-features/CONTRIBUTING.md) file to learn how to contribute to this extension.
