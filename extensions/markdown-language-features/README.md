# Language Features for Markdown files

**Notice:** This extension is bundled with Visual Studio Code. It can be disabled but not uninstalled.

## Features

See [Markdown in Visual Studio Code](https://code.visualstudio.com/docs/languages/markdown) to learn about the features of this extension.

The Markdown editor supports pasting image, video, and audio files from the keyboard or native context menu. It uses the same copy destinations, collision handling, and media snippets as the text editor. Clipboard files are retained lazily and transferred in sequential chunks of at most 256 KiB; no whole-file base64 payload or additional file-size limit is used. Applying the workspace edit still requires materialized file contents.
