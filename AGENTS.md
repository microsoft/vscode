## Design system

Before creating or changing UI, read [DESIGN.md](DESIGN.md) and the [component patterns](.agents/design/components.jsonc). Production VS Code controls, CSS, and theme resources remain authoritative; the catalog documents design intent and preview limitations, not shipping code or verified pixel parity.

The optional Colophon canvas can edit and preview the system (`copilot plugin install karkarl/colophon`, https://github.com/karkarl/colophon). Direct file editing works without the plugin.
