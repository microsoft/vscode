# Typography

Design guidance and example descriptions. Referenced registrations own the implemented values.

Sources: [SKILL.md](../../../../../../.github/skills/design-philosophy/SKILL.md), [design-tokens.instructions.md](../../../../../../.github/instructions/design-tokens.instructions.md).

## Introduction

Type roles carry hierarchy. Choose the role before choosing a font stack.

## Hierarchy and reading rhythm

Use headings, body text, and labels to distinguish the main task from supporting information.

## Weight and emphasis

Strong text uses the same role size with semibold weight. The shared UI ramp has two registered weights; editor text has its own configurable font settings.

## UI type roles

Headings use semibold; body and labels use regular. Sizes and use labels come from the current registrations.

## Reading metrics

Line-height and tracking values defined for the UI type roles.

## Font families

Native interface and monospace stacks for each platform. Actual font availability depends on this machine.

Editor font settings are separate from the UI type ramp.
