# Stroke

Design guidance and example descriptions. Referenced registrations own the implemented values.

Sources: [design-tokens.instructions.md](../../../../../../.github/instructions/design-tokens.instructions.md), [SKILL.md](../../../../../../.github/skills/ux-css-layout/SKILL.md).

## Introduction

Use a stroke to separate or define a boundary. Stroke thickness, control dimensions, and scrollbar width are different decisions.

## Use strokes to define boundaries

Use the {value} base stroke for standard dividers and control boundaries. Preserve stronger focus and contrast indicators where required.

## Stroke reference

Registered thickness for standard boundaries. Scrollbar dimensions and control hit areas are separate measurements.
