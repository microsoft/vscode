## Status meanings

| Status | Meaning |
| --- | --- |
| Implemented | The specified, bounded behavior exists. Linked tests are regression evidence, not universal deployment qualification. |
| Partial | Some enforcement exists; the named missing guarantee must not be inferred. |
| Not satisfied | The full requirement lacks enforcement. Its omission is not automatically an accepted deferral. |
| Deferred | The stronger guarantee is outside the agreed increment, not implemented. |
| Unverified | Code/packaging support exists, but the relevant deployment evidence is missing. |
| Out of scope | The requirement belongs to another compute/product variant and must not be enabled implicitly here. |

The implementation and verification columns point to enforcement and tests, not to the authority for a requirement. A WPS join or publish ACK does not establish AHP authentication, provider acceptance, durable persistence, or completed agent work.

## 1. Credentials never reach logs or disk, and are scrubbed on disposal

Source: [credential handling](https://github.com/github/copilot-host/blob/db3e5df9d3f3c5581d0a5ce96bdbe864ce1ac518/AGENTS.md?plain=1#L48). Host control-plane credentials, relay tickets and client GitHub credentials are distinct; only a validated client credential may sponsor user-local agent work.

## Evidence boundary

Current local regressions passed 318 Mission Control/core-server Node tests, 589 local/remote provider Electron tests (11 existing pending), and 263 WPS/client Electron tests, plus client types, changed-file lint and layering. These tests establish bounded behavior, not security certification or fleet stability.

Real isolated, sync-disabled OSS runs exercised native remote turns and verified shell output in both host directions. A completed two-hour run recorded 2,470 snapshots, 15 remote turns, 71 verified terminals and eight deliberate same-client reconnects. Original-owner history replay covered 92 sessions/184 snapshots, including a 1,546,452-byte chat; eight nonexistent historical working directories were explicitly excluded. Remote read state was verified at both frontend and authoritative host.

Unexpected host socket loss rejected some in-flight raw requests; host/client recovery preserved logical IDs. Held application session/chat subscriptions were separately verified across deliberate host loss, recovering in about 28.4 seconds with no subscription errors and subsequent remote work. Abrupt-close cause remains unconfirmed. The later three-hour recovery-aware run was interrupted by the maintainer's reboot; it is not a completed qualification run.

Source requirement, code enforcement, regression evidence, live deployment evidence and scope approval are different facts. None substitutes for the others.
