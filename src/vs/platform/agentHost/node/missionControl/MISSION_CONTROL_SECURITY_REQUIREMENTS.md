## Requirement sources

Requirements are grouped by topic, not by implementation status. Sources include the [Copilot Host security invariants](https://github.com/github/copilot-host/blob/db3e5df9d3f3c5581d0a5ce96bdbe864ce1ac518/AGENTS.md?plain=1#L44-L54), its architecture documents and protocol specifications, VS Code contracts, and user choices. Assistant proposals and design choices are labeled separately.

Copilot Host file/line citations refer to revision `db3e5df9d3f3c5581d0a5ce96bdbe864ce1ac518`. Copilot Host links require repository access. Protocol specifications define wire compatibility, not the implementation status of either host. Drafts and recommended defaults are labeled. The [token model](https://github.com/github/copilot-host/blob/db3e5df9d3f3c5581d0a5ce96bdbe864ce1ac518/docs/architecture/token-model.md?plain=1#L1-L8) describes target behavior, not an inventory of upstream implementation. Absolute VS Code implementation and test links are pinned to revision `0622f8dd27e63028aee8f5cc94131dd7650fafe9`; relative links follow the checkout. Companion documentation follows the PR branch.
